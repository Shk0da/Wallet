# Шакал

Личный финансовый дашборд (кодовое имя проекта — WALLET): все деньги семьи в
одном окне. Два режима — **📅 Календарь** и **📈 Портфель**, между которыми
можно переключаться одним кликом.

## Что умеет

**Календарь.** Каждый месяц по дням: зарплата, аванс и регулярные платежи
повторяются сами, разовые покупки добавляются парой кликов. Сразу видно,
сколько придёт и сколько уйдёт в любой день, на неделе и за месяц, а кнопка
«Скрыть суммы» прячет все цифры от посторонних глаз.

**Баланс по дням.** Бесконечная лента-график: будущее достраивается по мере
пролистывания (планируемые поступления и платежи уже учтены), прошлое идёт
до самой первой операции. Тап по дню открывает список операций этого дня.

**Портфель.** Синхронизация брокерских счетов Т-Инвестиций и Финам:
текущая стоимость, вложено, прибыль, все активы с долями и дивидендной
доходностью, предстоящие купоны и выплаты, разбивка по брокерам и секторам.
Отдельный раздел **Прогноз**: как будет расти капитал при текущих
пополнениях, когда пассивный доход достигнет заданной цели и что от него
останется с учётом инфляции.

**Ещё.** Тёмная тема, утренние уведомления о платежах дня, экспорт и импорт
данных файлом, демо-данные для знакомства.

## Два формата

| | Сервер (PHP) | Android-приложение |
|---|---|---|
| Данные | data.json / portfolio.json | localStorage + снапшот-файл |
| Синхронизация брокеров | по кнопке или расписанию | по кнопке, прямо с телефона |
| Утренние уведомления | cron → ntfy | будильник самого телефона |
| Токены брокеров | ⚙️ Настройки | ⚙️ Настройки |
| Пароль доступа | есть | нет (телефон = один пользователь) |

На телефоне интерфейс — мобильный, в стиле приложения Т-Банка: компактный
календарь, нижняя таб-панель, меню-бургер с разделами портфеля,
модалки-шиты снизу. На широких экранах и в вебе — десктопный дашборд.

## Android-приложение

`dist/wallet.apk` — полностью автономное: без сервера и внешних CDN (все
скрипты и шрифты внутри APK), данные — в памяти телефона.

- **Установка.** Разрешите установку из неизвестных источников и откройте
  APK. Требуется Android 7.0+ с обновлённым WebView.
- **Обновление.** Ставится поверх без потери данных, пока подпись та же.
- **Перенос данных.** Веб ⇄ телефон — JSON-файлом: «⚙️ Настройки» →
  «Данные» → экспорт/импорт. Токены брокеров по умолчанию не включаются
  (есть отдельный чекбокс).
- **Начало работы.** В настройках — токены T-Invest/Finam, время утреннего
  уведомления (по умолчанию 08:00) и тёмная тема.

## Сборка и тесты

```sh
./tools/build-apk.sh        # → dist/wallet.apk
node tools/test-offline.mjs # смоук-тесты офлайн-бандла и веб-режима
```

Тесты гоняют автономный бандл целиком в jsdom: календарь, настройки,
экспорт, импорт, синхронизация на стабах. Любыая попытка выйти в сеть
мимо Java-моста роняет тест.
