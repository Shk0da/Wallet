# WALLET

Личный финансовый дашборд: все деньги семьи в одном окне. Приложение совмещает
два режима — **📅 Календарь** и **📈 Портфель**, между которыми можно
переключаться одним кликом.

В календаре виден каждый месяц по дням: зарплата, аванс и регулярные платежи
повторяются сами, разовые покупки добавляются парой кликов. Сразу видно,
сколько придёт и сколько уйдёт в любой день, на неделе и за месяц, а кнопка
«Скрыть суммы» прячет все цифры от посторонних глаз.

Режим «Портфель» подтягивает брокерские счета Т-Инвестиций и Финам: текущая
стоимость, вложено, прибыль, предстоящие купоны и дивиденды, разбивка по
брокерам, типам активов и секторам. Отдельно строится прогноз: как будет
расти капитал при текущих пополнениях, когда пассивный доход достигнет
заданной цели и что от него останется с учётом инфляции.

## 🔄 Синхронизация брокеров из командной строки

`cli-sync.php` — та же синхронизация Т-Инвестиций и Финам, что и кнопка
«Синхронизация» на дашборде, но без веб-сервера: тонкая обёртка над
`sync.php` с тем же пайплайном. Общий `sync.lock` — с синхронизацией из
браузера запуски не конфликтуют, а `portfolio.json` записывается так же
атомарно. Авторизация не запрашивается: CLI-запуск — локальный доверенный
контекст (доступ к shell уже означает доступ к `settings.json`).

```sh
php cli-sync.php           # реальная синхронизация (T-Invest + Finam → portfolio.json)
php cli-sync.php --mock    # детерминированные демо-данные без сети (portfolio.json не трогает)
php cli-sync.php --help    # справка
```

Кронтаб (09:30 и 23:30 каждый день):

```
30 9,23 * * * /usr/bin/php /path/to/wallet/cli-sync.php >/dev/null 2>&1
```

Требования те же, что у всего проекта: PHP 7.4+ с расширением curl —
скрипт сам проверит версию и подскажет, если чего-то не хватает.

## 📲 Утренние уведомления о платежах (ntfy)

Каждое утро крон может присылать на Android пуш со списком сегодняшних
платежей календаря и итогом дня. Доставку делает [ntfy](https://ntfy.sh) —
данные скрипта уходят одним POST-запросом, телефон получает пуш через
приложение ntfy даже при закрытом браузере.

Настройка:

1. Установить на Android приложение **ntfy** (Google Play / F-Droid) и
   подписаться на новый топик, например `wallet-a1b2c3d4e5` (придумайте
   случайный — имя топика и есть доступ к нему).
2. Добавить топик в `settings.json` рядом с существующими секциями:

   ```json
   "notify": {
       "ntfyUrl": "https://ntfy.sh",
       "topic": "wallet-a1b2c3d4e5",
       "priority": 3
   }
   ```

   `ntfyUrl` можно указать на свой self-hosted сервер ntfy; `priority` (1–5) и
   `caFile` (CA-бандл для сетей с TLS-инспектором) необязательны.
3. Проверить вручную на машине с `data.json`:

   ```sh
   php notify-today.php --print   # показать сообщение, не отправляя
   php notify-today.php           # реальная отправка
   ```

4. Добавить в кронтаб (08:00 каждый день):

   ```
   0 8 * * * /usr/bin/php /path/to/wallet/notify-today.php >> /path/to/wallet/notify.log 2>&1
   ```

Скрипт считает «сегодня» по Europe/Moscow. Если платежей в этот день нет,
пуш не отправляется. Для отладки есть `--date=ГГГГ-ММ-ДД` и `--demo`
(фейковые данные без чтения `data.json`).

> ⚠️ Публичный ntfy.sh видит текст уведомлений (названия и суммы). Топик
> со случайным именем практически невозможно перебрать, но для полной
> приватности поднимите свой ntfy и укажите его в `ntfyUrl`.
