Брокеры

Токен выпускает сам брокер. Откройте приложение Т-Инвестиции: Профиль → Настройки → «API-доступ» и выпустите токен — достаточно права читать портфель (торговать не нужно).
В личном кабинете FinamTrade (finamtrade.ru): Настройки → «Trading API» → Issue access key. Ключ показывается один раз — скопируйте сразу после выпуска.
Токены хранятся на сервере и уходят в синхронизацию с брокерами. Пустое поле — текущий токен не меняется.
В APK токены хранятся только на устройстве.
